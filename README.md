A tiny Node program for make.fun's "One-Line Laugh-Off": it writes exactly one joke line — about asking an AI to make a sandwich and getting a picture of one instead — to `entry.txt`, after checking the line is non-empty, single-line, and within the competition's 200-character limit.

## Run it

```sh
node main.ts
```
